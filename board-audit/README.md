# Визуальная проверка полей RoboRally

PNG-файлы в этой папке создаются из сохранённых в `module.js` координат поверх исходных изображений из `Roborally/Поля целиком`.

- пурпурная стрелка — клетка и направление конвейера;
- голубая заливка — экспресс-конвейер;
- красная заливка — яма;
- зелёная рамка — ремонтный ключ;
- оранжевая окружность — шестерня;
- голубая линия — стена;
- зелёная линия — фактический путь лазера до стены или края поля;
- фиолетовый блок — толкатель с номерами активных регистров;
- полупрозрачный зелёный круг — флаг курса;
- синий круг на стартовой карте — стартовая позиция.

Пересоздать все изображения и `manifest.json` (работает и с portable Node из `demo-server`):

```powershell
.\scripts\render-board-audit.ps1
```

Размер стороны основного поля по умолчанию — 1800 пикселей. Для другого размера:

```powershell
.\scripts\render-board-audit.ps1 -Size 2400
```

Если `npm` доступен в `PATH`, эквивалентная команда: `npm run audit:boards`.
